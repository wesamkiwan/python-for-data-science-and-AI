# 📚 Module 15 References: Ensemble Methods & Advanced ML

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[StatQuest — Random Forests](https://www.youtube.com/@statquest)** — the clearest free explanation of bagging and Random Forest, step by step.
- 🟢 **[StatQuest — Gradient Boost & XGBoost](https://www.youtube.com/@statquest)** — an excellent, patient walkthrough of how boosting actually works mathematically, made intuitive.
- 🟢 **[Krish Naik — XGBoost & LightGBM Tutorials](https://www.youtube.com/@krishnaik06)** — practical, code-first walkthroughs of both libraries.
- 🟡 **[Kaggle — Hyperparameter Tuning Livestreams/Tutorials](https://www.youtube.com/@kaggle)** — real, practical tuning workflows from Kaggle Grandmasters.

## 📖 Official Documentation
- 🟢 **[scikit-learn — Ensemble Methods](https://scikit-learn.org/stable/modules/ensemble.html)** — the authoritative reference for Random Forest, bagging, and boosting variants scikit-learn provides.
- 🟢 **[XGBoost — Official Documentation](https://xgboost.readthedocs.io/)** — the definitive reference for XGBoost, including its Python API.
- 🟢 **[LightGBM — Official Documentation](https://lightgbm.readthedocs.io/)** — the definitive reference for LightGBM.
- 🟢 **[scikit-learn — Tuning Hyperparameters](https://scikit-learn.org/stable/modules/grid_search.html)** — official reference for `GridSearchCV` and `RandomizedSearchCV`.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — A Practical Guide to Ensemble Learning](https://realpython.com/)** — search this title for a thorough, code-driven ensemble methods walkthrough.
- 🟢 **[Machine Learning Mastery — A Gentle Introduction to XGBoost](https://machinelearningmastery.com/gentle-introduction-xgboost-applied-machine-learning/)** — a widely-cited, practical introduction.
- 🟡 **[Towards Data Science — Hyperparameter Tuning: GridSearch vs. RandomSearch](https://towardsdatascience.com/)** — search this title; a commonly recommended, practical comparison.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Intermediate Machine Learning](https://www.kaggle.com/learn/intermediate-machine-learning)** — free course directly covering Random Forest, XGBoost, and cross-validation-based tuning.
- 🟢 **[Kaggle Competitions](https://www.kaggle.com/competitions)** — the best place to see ensemble methods applied in real, competitive practice, with shared winning solution write-ups.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Kaggle Datasets](https://www.kaggle.com/datasets)** — practice Random Forest/XGBoost/LightGBM and hyperparameter tuning on real, messy data.
- 🟡 **[Papers With Code — Tabular Data Leaderboards](https://paperswithcode.com/)** — see current state-of-the-art results on tabular benchmarks, most driven by boosting methods.

## 📚 Books
- 🟢 **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron** — its ensemble methods chapter covers Random Forest and boosting at exactly this practical depth.
- 🟡 **"The Elements of Statistical Learning" by Hastie, Tibshirani, and Friedman** (free online) — the deeper mathematical foundations of boosting, bagging, and tree-based methods, for those who want the full theory.

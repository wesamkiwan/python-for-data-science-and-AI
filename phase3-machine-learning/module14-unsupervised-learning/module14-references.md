# 📚 Module 14 References: Unsupervised Learning & Clustering

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[StatQuest — K-means clustering](https://www.youtube.com/@statquest)** — the clearest free explanation of how K-Means actually works, step by step.
- 🟢 **[StatQuest — PCA Main Ideas](https://www.youtube.com/@statquest)** — excellent, highly visual intuition for PCA without heavy math.
- 🟢 **[StatQuest — Hierarchical Clustering](https://www.youtube.com/@statquest)** — clear walkthrough of dendrograms and the merging process.

## 📖 Official Documentation
- 🟢 **[scikit-learn — Clustering](https://scikit-learn.org/stable/modules/clustering.html)** — the authoritative reference covering K-Means, hierarchical clustering, and every other clustering algorithm scikit-learn offers.
- 🟢 **[scikit-learn — Decomposing Signals (PCA)](https://scikit-learn.org/stable/modules/decomposition.html#pca)** — official reference for PCA and related dimensionality reduction techniques.
- 🟢 **[SciPy — Hierarchical Clustering](https://docs.scipy.org/doc/scipy/reference/cluster.hierarchy.html)** — reference for `linkage()` and `dendrogram()`, used in this module's dendrogram examples.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — K-Means Clustering in Python: A Practical Guide](https://realpython.com/k-means-clustering-python/)** — thorough, practical walkthrough matching this module's scope.
- 🟢 **[Towards Data Science — A One-Stop Shop for Principal Component Analysis](https://towardsdatascience.com/)** — search this title; a commonly recommended, example-driven PCA deep dive.
- 🟡 **[Machine Learning Mastery — How to Choose the Number of Clusters](https://machinelearningmastery.com/)** — search this title; covers the elbow method and alternatives in depth.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Unsupervised Learning](https://www.kaggle.com/learn)** (check current Kaggle Learn catalog — clustering content is often folded into broader ML courses) — free, hands-on practice.
- 🟡 **[Andrew Ng's Machine Learning Specialization (Coursera)](https://www.coursera.org/specializations/machine-learning-introduction)** — its unsupervised learning course covers K-Means and PCA with strong mathematical grounding; free to audit.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Visualizing K-Means Clustering (naftaliharris.com)](https://www.naftaliharris.com/blog/visualizing-k-means-clustering/)** — an excellent interactive tool that animates K-Means step by step on data you control.
- 🟡 **[Explained Visually — PCA](https://setosa.io/ev/principal-component-analysis/)** — an interactive, visual explanation of PCA that builds strong geometric intuition.

## 📚 Books
- 🟢 **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron** — its unsupervised learning chapter covers clustering and PCA at exactly this practical level.
- 🟡 **"An Introduction to Statistical Learning" by James, Witten, Hastie, and Tibshirani** (free online) — has a strong, more mathematically grounded chapter on unsupervised learning.

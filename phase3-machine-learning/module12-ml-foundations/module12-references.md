# 📚 Module 12 References: ML Foundations (scikit-learn)

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[StatQuest — Machine Learning Fundamentals](https://www.youtube.com/@statquest)** — the best free resource for building genuine intuition behind ML concepts (logistic regression, precision/recall, R²) before diving into code.
- 🟢 **[Krish Naik — scikit-learn Full Course](https://www.youtube.com/@krishnaik06)** — practical, project-based scikit-learn walkthroughs.
- 🟡 **[3Blue1Brown — But what is a neural network?](https://www.youtube.com/@3blue1brown)** — not scikit-learn specific, but exceptional visual intuition for ML in general; a great primer ahead of Phase 4.

## 📖 Official Documentation
- 🟢 **[scikit-learn — Getting Started](https://scikit-learn.org/stable/getting_started.html)** — the official quickstart, covering the `.fit()`/`.predict()` pattern directly from the source.
- 🟢 **[scikit-learn — Supervised Learning Guide](https://scikit-learn.org/stable/supervised_learning.html)** — comprehensive reference for every classification/regression algorithm scikit-learn offers.
- 🟢 **[scikit-learn — Model Evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)** — the authoritative reference for every metric covered in this module and many more.
- 🟢 **[scikit-learn — Toy Datasets](https://scikit-learn.org/stable/datasets/toy_dataset.html)** — reference for `load_iris`, `load_wine`, and the other built-in datasets.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Split Your Dataset With scikit-learn's train_test_split()](https://realpython.com/train-test-split-python-data/)** — thorough, practical guide to this module's most important habit.
- 🟢 **[Real Python — Logistic Regression in Python](https://realpython.com/logistic-regression-python/)** — clear, example-driven walkthrough of classification fundamentals.
- 🟡 **[Towards Data Science — Precision vs. Recall](https://towardsdatascience.com/)** — search this title; a commonly recommended, visual explanation of the precision/recall tradeoff.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Intro to Machine Learning](https://www.kaggle.com/learn/intro-to-machine-learning)** — free, short, hands-on, and directly matches this module's scope.
- 🟢 **[Google's Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course)** — free, thorough, widely respected introduction covering classification, regression, and evaluation metrics in depth.
- 🟡 **[Andrew Ng's Machine Learning Specialization (Coursera)](https://www.coursera.org/specializations/machine-learning-introduction)** — the most famous ML course in the field; free to audit, deeper mathematical grounding than this module.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Kaggle Competitions](https://www.kaggle.com/competitions)** — practice building and submitting real models once fundamentals are comfortable.
- 🟡 **[A Visual Introduction to Machine Learning (r2d3)](http://www.r2d3.us/visual-intro-to-machine-learning-part-1/)** — a beautifully interactive, scroll-driven visual explanation of how classification models work.

## 📚 Books
- 🟢 **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron** — the definitive, most-recommended practical ML book covering scikit-learn thoroughly, and a direct bridge into Phase 4's deep learning content.
- 🟡 **"An Introduction to Statistical Learning" by James, Witten, Hastie, and Tibshirani** (free online) — more mathematically grounded, excellent for understanding *why* these algorithms work, not just how to call them.

## 👥 Communities
- **[r/MachineLearning](https://www.reddit.com/r/MachineLearning/)** and **[r/learnmachinelearning](https://www.reddit.com/r/learnmachinelearning/)** — active communities, the latter specifically beginner-friendly.
- **[Stack Overflow — [scikit-learn] tag](https://stackoverflow.com/questions/tagged/scikit-learn)** — nearly every scikit-learn error message or usage question has already been answered.

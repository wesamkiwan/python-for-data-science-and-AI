# 📚 Module 01 References: Python Fundamentals

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Programming with Mosh — Python Full Course for Beginners](https://www.youtube.com/@programmingwithmosh)** — clear, structured walkthrough of exactly the syntax covered in this module.
- 🟢 **[Corey Schafer — Python Tutorials](https://www.youtube.com/@coreyms)** — excellent deep-dive videos on individual topics (strings, dictionaries, f-strings); great for reinforcing specific concepts.
- 🟢 **[freeCodeCamp.org — Python for Beginners](https://www.youtube.com/@freecodecamp)** — long-form full course, good if you like a single continuous video to follow along with.

## 📖 Official Documentation
- 🟢 **[The Python Tutorial (docs.python.org)](https://docs.python.org/3/tutorial/)** — the authoritative, official introduction to Python; Sections 3-5 map directly to this module.
- 🟢 **[Built-in Types Reference](https://docs.python.org/3/library/stdtypes.html)** — the definitive reference for every method available on `str`, `list`, `dict`, `set`, etc.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Python Basics](https://realpython.com/learning-paths/python3-introduction/)** — consistently high-quality, practical written tutorials with runnable examples.
- 🟢 **[W3Schools Python Tutorial](https://www.w3schools.com/python/)** — good for quick syntax lookups with an in-browser "Try it Yourself" editor.

## 🎓 Courses & Learning Portals
- 🟢 **[freeCodeCamp — Scientific Computing with Python](https://www.freecodecamp.org/learn/scientific-computing-with-python/)** — free, project-based, and directly relevant to the data science track.
- 🟢 **[Python for Everybody (Coursera, Dr. Chuck)](https://www.coursera.org/specializations/python)** — free to audit; one of the most respected beginner Python specializations.
- 🟡 **[DataCamp — Introduction to Python](https://www.datacamp.com/courses/intro-to-python-for-data-science)** — paid, but built specifically for data science learners; in-browser exercises.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Python Tutor](https://pythontutor.com/)** — visualizes exactly how variables and memory change line-by-line as your code runs; fantastic for building a correct mental model of assignment and loops.
- 🟢 **[repl.it / replit.com](https://replit.com/)** — run Python in-browser with zero setup, useful if you want to experiment before or alongside installing locally.
- 🟡 **[LeetCode — Easy Python problems](https://leetcode.com/problemset/?difficulty=EASY)** — practice applying loops/conditionals/collections to small problems.

## 📚 Books
- 🟢 **"Python Crash Course" by Eric Matthes** — widely recommended as the best true-beginner Python book, with practical projects.
- 🟡 **"Fluent Python" by Luciano Ramalho** — not for absolute beginners, but the definitive book for truly understanding *why* Python works the way it does; save this for after Phase 1.

## 👥 Communities
- **[r/learnpython](https://www.reddit.com/r/learnpython/)** — beginner-friendly subreddit, very active and welcoming to basic questions.
- **[Python Discord](https://pythondiscord.com/)** — large, active community with dedicated help channels for beginners.
- **Stack Overflow — [python] tag](https://stackoverflow.com/questions/tagged/python)** — search here first; almost every beginner error message has already been answered.

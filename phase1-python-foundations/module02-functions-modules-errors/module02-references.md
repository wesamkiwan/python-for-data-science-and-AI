## 📖 Official Documentation
- 🟢 **[Python Tutorial — Defining Functions](https://docs.python.org/3/tutorial/controlflow.html#defining-functions)** — the authoritative walkthrough of default arguments, keyword arguments, and `*args`/`**kwargs`.
- 🟢 **[Python Tutorial — Modules](https://docs.python.org/3/tutorial/modules.html)** — official explanation of modules, packages, and the import system.
- 🟢 **[Python Tutorial — Errors and Exceptions](https://docs.python.org/3/tutorial/errors.html)** — the definitive reference for `try`/`except`/`else`/`finally` and the built-in exception hierarchy.
- 🟡 **[Built-in Exceptions Reference](https://docs.python.org/3/library/exceptions.html)** — full list of every built-in exception type (`ValueError`, `KeyError`, `TypeError`, etc.) and when Python raises each.

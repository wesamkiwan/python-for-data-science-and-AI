# 📚 Module 04 References: File I/O, JSON/CSV & APIs

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Python File Objects](https://www.youtube.com/@coreyms)** — clear, dedicated walkthrough of `open()`, context managers, and reading/writing files.
- 🟢 **[Corey Schafer — Working with JSON Data](https://www.youtube.com/@coreyms)** — covers `json.load`/`dump` and API responses in the same style as this module.
- 🟢 **[freeCodeCamp — Python Requests Library Tutorial](https://www.youtube.com/@freecodecamp)** — full walkthrough of the `requests` library, GET requests, and handling responses.

## 📖 Official Documentation
- 🟢 **[Python Tutorial — Reading and Writing Files](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files)** — the authoritative reference on file modes and the `with` statement.
- 🟢 **[`json` — JSON encoder and decoder](https://docs.python.org/3/library/json.html)** — full standard library reference for `dump`/`dumps`/`load`/`loads` and their options.
- 🟢 **[`csv` — CSV File Reading and Writing](https://docs.python.org/3/library/csv.html)** — full standard library reference for `reader`, `writer`, `DictReader`, `DictWriter`.
- 🟢 **[Requests — Quickstart](https://requests.readthedocs.io/en/latest/user/quickstart/)** — the official `requests` library guide; covers everything in this module and more (POST requests, headers, auth, sessions).

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Reading and Writing Files in Python](https://realpython.com/read-write-files-python/)** — thorough, practical walkthrough matching this module's depth.
- 🟢 **[Real Python — Working With JSON Data in Python](https://realpython.com/python-json/)** — excellent deep dive on JSON serialization/deserialization.
- 🟢 **[Real Python — Python's requests Library (Guide)](https://realpython.com/python-requests/)** — comprehensive guide covering GET/POST, status codes, and error handling in depth.

## 🎓 Courses & Learning Portals
- 🟢 **[freeCodeCamp — Scientific Computing with Python](https://www.freecodecamp.org/learn/scientific-computing-with-python/)** — same free track referenced in prior modules, includes a file-handling project.
- 🟡 **[Postman Academy — API Fundamentals Student Expert](https://academy.postman.com/)** — free, hands-on introduction to APIs and HTTP concepts (status codes, methods, requests) from the tool most professionals use to test APIs manually.

## 🌐 Websites & Interactive Platforms
- 🟢 **[JSONPlaceholder](https://jsonplaceholder.typicode.com/)** — the free fake REST API used throughout this module's examples; safe to practice GET requests against with no API key required.
- 🟢 **[httpbin.org](https://httpbin.org/)** — a simple HTTP request/response testing service; useful for experimenting with status codes, headers, and request methods.
- 🟡 **[Public APIs (GitHub list)](https://github.com/public-apis/public-apis)** — a huge curated list of free public APIs across every domain, once you want to practice beyond JSONPlaceholder.

## 📚 Books
- 🟢 **"Python Crash Course" by Eric Matthes** — its "Working with Data" chapters cover file handling and JSON in the same practical style.
- 🟡 **"Fluent Python" by Luciano Ramalho** — has a deeper treatment of Python's I/O model and iterators, worth returning to after Phase 1.

# 📚 Module 05 References: Tooling & Environments

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Python Virtual Environments](https://www.youtube.com/@coreyms)** — clear, dedicated walkthrough of `venv` and why it matters.
- 🟢 **[Corey Schafer — Git & GitHub Tutorial for Beginners](https://www.youtube.com/@coreyms)** — the most commonly recommended free git/GitHub crash course; covers everything in this module plus more.
- 🟢 **[freeCodeCamp — Git and GitHub for Beginners](https://www.youtube.com/@freecodecamp)** — long-form, hands-on full course.
- 🟡 **[VS Code official YouTube channel](https://www.youtube.com/@code)** — short, focused tips videos straight from the VS Code team, including Python-specific setup and debugging.

## 📖 Official Documentation
- 🟢 **[Python Docs — `venv` module](https://docs.python.org/3/library/venv.html)** — the authoritative reference for virtual environments.
- 🟢 **[pip documentation](https://pip.pypa.io/en/stable/)** — official reference for every `pip` command and option.
- 🟢 **[Git — Reference Manual](https://git-scm.com/docs)** — the complete, official command reference for git.
- 🟢 **[GitHub Docs — Hello World](https://docs.github.com/en/get-started/quickstart/hello-world)** — GitHub's own beginner walkthrough of repos, branches, and pull requests.
- 🟢 **[VS Code Docs — Python in VS Code](https://code.visualstudio.com/docs/python/python-tutorial)** — official setup and usage guide for the Python extension.
- 🟢 **[VS Code Docs — Debugging](https://code.visualstudio.com/docs/editor/debugging)** — the authoritative guide to breakpoints, stepping, and the debugger UI.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Python Virtual Environments: A Primer](https://realpython.com/python-virtual-environments-a-primer/)** — thorough, practical walkthrough with common pitfalls covered.
- 🟢 **[Atlassian — Git Tutorials](https://www.atlassian.com/git/tutorials)** — exceptionally clear, visual explanations of git concepts (branching, merging, staging) from Bitbucket's parent company.
- 🟡 **[GitHub — gitignore templates](https://github.com/github/gitignore)** — official, curated `.gitignore` templates for every language/tool, including a ready-made Python one.

## 🎓 Courses & Learning Portals
- 🟢 **[GitHub Skills](https://skills.github.com/)** — free, interactive, guided exercises directly on GitHub covering git basics, pull requests, and collaboration.
- 🟢 **[Learn Git Branching](https://learngitbranching.js.org/)** — a free, visual, interactive way to practice git commands and branching without any setup.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Learn Git Branching](https://learngitbranching.js.org/)** — (also listed above) practice branch/merge scenarios visually in the browser.
- 🟢 **[gitignore.io](https://www.toptal.com/developers/gitignore)** — generates a tailored `.gitignore` file for any combination of languages/tools/editors.
- 🟡 **[oh-my-git](https://ohmygit.org/)** — a free, open-source game that teaches git concepts through play.

## 📚 Books
- 🟢 **"Pro Git" by Scott Chacon & Ben Straub** — the definitive, freely available (progit.org) book on git, from beginner to advanced.
- 🟡 **"Python Crash Course" by Eric Matthes** — its appendix on installing and troubleshooting a Python environment complements this module well.

## 👥 Communities
- **[r/git](https://www.reddit.com/r/git/)** — dedicated subreddit for git questions, including plenty of beginner-friendly threads.
- **[r/learnpython](https://www.reddit.com/r/learnpython/)** — good for environment/`pip`-related troubleshooting.
- **[Stack Overflow — [git] tag](https://stackoverflow.com/questions/tagged/git)** — practically every git error message and workflow question has already been answered here.

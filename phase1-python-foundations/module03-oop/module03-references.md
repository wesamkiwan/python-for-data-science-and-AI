# 📚 Module 03 References: Object-Oriented Programming

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Python OOP Tutorials](https://www.youtube.com/@coreyms)** — the definitive video series on Python classes, inheritance, and dunder/"magic" methods; widely considered the best free OOP walkthrough available.
- 🟢 **[Programming with Mosh — Python OOP](https://www.youtube.com/@programmingwithmosh)** — clear, structured coverage of this module's exact topics.
- 🟡 **[ArjanCodes — Python OOP design patterns](https://www.youtube.com/@ArjanCodes)** — more advanced perspective on when (and when not) to use OOP; good to revisit after this module solidifies.

## 📖 Official Documentation
- 🟢 **[Python Tutorial — Classes](https://docs.python.org/3/tutorial/classes.html)** — the authoritative walkthrough of classes, inheritance, and scope rules directly from the Python docs.
- 🟡 **[Data Model — Special Method Names](https://docs.python.org/3/reference/datamodel.html#special-method-names)** — the full reference for every dunder method Python supports (`__str__`, `__repr__`, `__eq__`, and many more beyond this module's scope).

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Object-Oriented Programming (OOP) in Python 3](https://realpython.com/python3-object-oriented-programming/)** — thorough, practical, and matches this module's structure closely.
- 🟢 **[Real Python — Inheritance and Composition](https://realpython.com/inheritance-composition-python/)** — goes a bit further, comparing inheritance ("is-a") against composition ("has-a") as design choices.
- 🟡 **[Real Python — Python's `@property`](https://realpython.com/python-property/)** — deep dive on properties, getters, and setters beyond this module's introduction.

## 🎓 Courses & Learning Portals
- 🟢 **[freeCodeCamp — Scientific Computing with Python](https://www.freecodecamp.org/learn/scientific-computing-with-python/)** — continues the same free, project-based track referenced in Modules 01-02, including OOP projects.
- 🟢 **[Python for Everybody (Coursera, Dr. Chuck)](https://www.coursera.org/specializations/python)** — free to audit; its OOP-focused course covers this module's material at the same beginner pace.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Python Tutor](https://pythontutor.com/)** — visualize objects, their attributes, and method calls in memory step by step; extremely helpful for cementing how `self` and inheritance actually work.
- 🟡 **[LeetCode — Design/OOP problems](https://leetcode.com/tag/design/)** — practice modeling small systems with classes once the basics feel solid.

## 📚 Books
- 🟢 **"Introduction to Computation and Programming Using Python" by John V. Guttag** — MIT's intro CS textbook (companion to the 6.0001/6.0002 courses); its OOP chapter builds a `Person` class around classic explicit `get_name()`/`set_birthday()`/`get_age()` getter and setter methods before touching anything Python-specific — a great scaffold for seeing the "any OOP language" version of the pattern this module's `@property` section builds on.
- 🟢 **"Python Crash Course" by Eric Matthes** — its Classes chapter matches this module's beginner-friendly pacing closely.
- 🟡 **"Fluent Python" by Luciano Ramalho** — has an outstanding, much deeper treatment of dunder methods and the Python data model; ideal follow-up reading once Phase 1 is complete.
- 🟡 **"Design Patterns: Elements of Reusable Object-Oriented Software" (Gang of Four)** — the classic reference on OOP design patterns; a longer-term read for after you're comfortable with these fundamentals.

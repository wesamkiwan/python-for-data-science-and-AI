# 📚 Module 09 References: Data Visualization

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Matplotlib Tutorials](https://www.youtube.com/@coreyms)** — the most commonly recommended free Matplotlib series; covers the Figure/Axes model clearly.
- 🟢 **[Keith Galli — Matplotlib Full Course](https://www.youtube.com/@KeithGalli)** — hands-on, project-based, covers all the core chart types from this module.
- 🟢 **[Rob Mulla — Seaborn Data Visualization](https://www.youtube.com/@robmulla)** — practical, real-dataset-driven Seaborn walkthrough.
- 🟡 **[Plotly's official YouTube channel](https://www.youtube.com/@PlotlyGraphingLibraries)** — short, focused tutorials straight from the library's own team.

## 📖 Official Documentation
- 🟢 **[Matplotlib — Quick Start Guide](https://matplotlib.org/stable/tutorials/introductory/quick_start.html)** — the official introduction to the Figure/Axes model.
- 🟢 **[Matplotlib — Gallery](https://matplotlib.org/stable/gallery/index.html)** — hundreds of example charts with full source code; the fastest way to find "how do I make a chart that looks like X."
- 🟢 **[Seaborn — Official Tutorial](https://seaborn.pydata.org/tutorial.html)** — clear, example-driven, from the library's own maintainers.
- 🟢 **[Seaborn — Example Gallery](https://seaborn.pydata.org/examples/index.html)** — visual gallery of every chart type Seaborn supports.
- 🟢 **[Plotly Express — Official Docs](https://plotly.com/python/plotly-express/)** — the authoritative reference for the high-level interface covered in this module.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Python Plotting With Matplotlib](https://realpython.com/python-matplotlib-guide/)** — thorough, practical walkthrough matching this module's depth.
- 🟢 **[Real Python — Data Visualization With Seaborn](https://realpython.com/python-seaborn-tutorial/)** — clear, example-heavy guide to Seaborn's statistical charts.
- 🟡 **[Towards Data Science — Interactive Data Visualization with Plotly](https://towardsdatascience.com/)** — search this title; commonly recommended for going beyond `plotly.express` basics.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Data Visualization](https://www.kaggle.com/learn/data-visualization)** — free, short, hands-on course specifically on Seaborn.
- 🟢 **[freeCodeCamp — Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/)** — continues the free track referenced in prior modules, includes a visualization project.

## 🌐 Websites & Interactive Platforms
- 🟢 **[The Python Graph Gallery](https://python-graph-gallery.com/)** — an enormous, well-organized gallery of chart types across Matplotlib/Seaborn/Plotly, each with runnable code.
- 🟡 **[From Data to Viz](https://www.data-to-viz.com/)** — a decision-tree-style tool for choosing the right chart type for your specific data shape — a great companion to this module's chart-type decision table.

## 📚 Books
- 🟢 **"Storytelling with Data" by Cole Nussbaumer Knaflic** — not code-focused, but the standard reference on what makes a chart actually communicate well — a great complement to the technical skills in this module.
- 🟡 **"Python Data Science Handbook" by Jake VanderPlas** (free online) — its visualization chapters cover Matplotlib and Seaborn in depth, alongside the NumPy/Pandas material from earlier modules.

## 👥 Communities
- **[r/dataisbeautiful](https://www.reddit.com/r/dataisbeautiful/)** — great for visualization inspiration and critique, though not code-support focused.
- **[Stack Overflow — [matplotlib] / [seaborn] / [plotly] tags](https://stackoverflow.com/questions/tagged/matplotlib)** — nearly every chart-formatting question has already been answered across these tags.

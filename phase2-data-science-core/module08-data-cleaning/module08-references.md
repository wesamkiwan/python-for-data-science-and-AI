# 📚 Module 08 References: Data Cleaning & Wrangling

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Pandas: Handling Missing Data](https://www.youtube.com/@coreyms)** — clear, dedicated walkthrough of `.isna()`, `.dropna()`, `.fillna()`.
- 🟢 **[Keith Galli — Data Cleaning with Pandas](https://www.youtube.com/@KeithGalli)** — hands-on, full-dataset cleaning walkthrough covering duplicates, dtypes, and strings together.
- 🟡 **[StatQuest — Outlier Detection Explained](https://www.youtube.com/@statquest)** — clear, visual explanation of IQR and z-score concepts from a statistics-first angle.

## 📖 Official Documentation
- 🟢 **[Pandas — Working with Missing Data](https://pandas.pydata.org/docs/user_guide/missing_data.html)** — the authoritative guide to `NaN`/`NaT` handling.
- 🟢 **[Pandas — `pandas.to_numeric`](https://pandas.pydata.org/docs/reference/api/pandas.to_numeric.html)** and **[`pandas.to_datetime`](https://pandas.pydata.org/docs/reference/api/pandas.to_datetime.html)** — official reference for both conversion functions and their `errors=` options.
- 🟢 **[Pandas — Working with Text Data](https://pandas.pydata.org/docs/user_guide/text.html)** — the full `.str` accessor reference.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Dealing With Missing Data in Python](https://realpython.com/python-data-cleaning-numpy-pandas/)** — practical, example-driven walkthrough matching this module's scope.
- 🟢 **[Real Python — Pandas: How to Read and Write Files](https://realpython.com/pandas-read-write-files/)** — covers common data-loading gotchas (encoding, delimiters) that often surface as "dirty data" issues.
- 🟡 **[Towards Data Science — Outlier Detection Methods Compared](https://towardsdatascience.com/)** — search this title; a commonly recommended comparison of IQR vs. z-score vs. other methods.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Data Cleaning](https://www.kaggle.com/learn/data-cleaning)** — free, short, hands-on course specifically on this module's exact topics (missing values, scaling, dates, inconsistent text, duplicates).
- 🟢 **[freeCodeCamp — Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/)** — continues the free track referenced in prior modules.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Kaggle Datasets](https://www.kaggle.com/datasets)** — search for "messy" or real-world datasets to practice cleaning techniques on authentic, imperfect data.
- 🟡 **[Awesome Public Datasets (GitHub)](https://github.com/awesomedata/awesome-public-datasets)** — curated list of real datasets, many of which need genuine cleaning before analysis.

## 📚 Books
- 🟢 **"Python for Data Analysis" by Wes McKinney** — its data cleaning chapters are considered a standard reference, written by Pandas' own creator.
- 🟡 **"Bad Data Handbook" by Q. Ethan McCallum (ed.)** — a well-known collection of real-world data-quality war stories; more anecdotal than technical, but great for building intuition about what "messy data" really looks like on the job.

## 👥 Communities
- **[r/datascience](https://www.reddit.com/r/datascience/)** and **[r/dataengineering](https://www.reddit.com/r/dataengineering/)** — active communities for data-quality and cleaning discussions.
- **[Stack Overflow — [pandas] + [data-cleaning] tags](https://stackoverflow.com/questions/tagged/pandas+data-cleaning)** — most cleaning-related error messages and edge cases have already been discussed here.

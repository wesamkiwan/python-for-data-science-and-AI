# 📚 Module 07 References: Pandas for Data Manipulation

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Corey Schafer — Pandas Tutorials](https://www.youtube.com/@coreyms)** — the most commonly recommended free Pandas series; covers Series/DataFrames, filtering, and groupby in the same order as this module.
- 🟢 **[Keith Galli — Complete Pandas Tutorial](https://www.youtube.com/@KeithGalli)** — hands-on, project-based walkthrough of real datasets.
- 🟡 **[Rob Mulla — Pandas groupby explained](https://www.youtube.com/@robmulla)** — focused, visual explanation of split-apply-combine specifically.

## 📖 Official Documentation
- 🟢 **[Pandas — 10 Minutes to pandas](https://pandas.pydata.org/docs/user_guide/10min.html)** — the official quickstart, covering almost everything in this module concisely.
- 🟢 **[Pandas — User Guide](https://pandas.pydata.org/docs/user_guide/index.html)** — the full, authoritative guide; the "Group by" and "Merge, join, concatenate" sections map directly to this module's later lessons.
- 🟡 **[Pandas — API Reference](https://pandas.pydata.org/docs/reference/index.html)** — the complete method-by-method reference, useful once you know roughly what you're looking for.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — pandas DataFrame: Working With Data Efficiently](https://realpython.com/pandas-dataframe/)** — thorough, practical, matches this module's scope.
- 🟢 **[Real Python — pandas GroupBy: Your Guide to Grouping Data](https://realpython.com/pandas-groupby/)** — an excellent, example-heavy deep dive on split-apply-combine.
- 🟢 **[Real Python — Combining Data in Pandas With merge(), .join(), and concat()](https://realpython.com/pandas-merge-join-and-concat/)** — clears up exactly the merge/concat distinctions covered in this module.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Pandas](https://www.kaggle.com/learn/pandas)** — free, short, and extremely hands-on with real datasets; widely considered one of the best free Pandas courses available.
- 🟢 **[freeCodeCamp — Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/)** — free, project-based, continues the track referenced in Module 06.
- 🟡 **[DataCamp — Data Manipulation with pandas](https://www.datacamp.com/courses/data-manipulation-with-pandas)** — paid, in-browser exercises specifically on this module's topics.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Pandas Cheat Sheet (official, PDF)](https://pandas.pydata.org/Pandas_Cheat_Sheet.pdf)** — a dense, official one-page reference — a good companion to this module's own cheat sheet.
- 🟡 **[Kaggle Datasets](https://www.kaggle.com/datasets)** — practice everything in this module against thousands of free, real-world datasets.

## 📚 Books
- 🟢 **"Python for Data Analysis" by Wes McKinney** — written by the creator of Pandas itself; the definitive, most-cited book on the library.
- 🟡 **"Effective Pandas" by Matt Harrison** — focused specifically on idiomatic, high-performance Pandas patterns; a strong follow-up once fundamentals are solid.

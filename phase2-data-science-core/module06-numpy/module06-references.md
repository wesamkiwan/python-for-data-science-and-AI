# 📚 Module 06 References: NumPy Fundamentals

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[Keith Galli — Complete NumPy Tutorial](https://www.youtube.com/@KeithGalli)** — one of the most-recommended free NumPy walkthroughs; covers arrays, indexing, and broadcasting hands-on.
- 🟢 **[freeCodeCamp — NumPy Full Course](https://www.youtube.com/@freecodecamp)** — long-form, comprehensive, beginner-friendly.
- 🟡 **[NeuralNine — NumPy Broadcasting Explained](https://www.youtube.com/@NeuralNine)** — focused, visual explanation specifically of broadcasting rules, which trips up a lot of learners.

## 📖 Official Documentation
- 🟢 **[NumPy — Absolute Beginners Guide](https://numpy.org/doc/stable/user/absolute_beginners.html)** — the official, extremely well-written starting point maintained by the NumPy team itself.
- 🟢 **[NumPy — Array Broadcasting](https://numpy.org/doc/stable/user/basics.broadcasting.html)** — the authoritative, precise explanation of broadcasting rules straight from the source.
- 🟡 **[NumPy — Routines Reference](https://numpy.org/doc/stable/reference/routines.html)** — the full function reference; useful once you know roughly what you're looking for.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — NumPy Tutorial: Your First Steps Into Data Science](https://realpython.com/numpy-tutorial/)** — thorough, practical, matches this module's scope closely.
- 🟢 **[Real Python — Look Ma, No For-Loops: Array Programming With NumPy](https://realpython.com/numpy-array-programming/)** — excellent deep dive specifically on vectorization and why it's fast.
- 🟡 **[Towards Data Science — Understanding Broadcasting in NumPy](https://towardsdatascience.com/)** — search this title; a commonly recommended visual walkthrough of broadcasting with diagrams.

## 🎓 Courses & Learning Portals
- 🟢 **[freeCodeCamp — Data Analysis with Python](https://www.freecodecamp.org/learn/data-analysis-with-python/)** — free, includes a dedicated NumPy section with hands-on projects.
- 🟡 **[DataCamp — Introduction to NumPy](https://www.datacamp.com/courses/introduction-to-numpy)** — paid, but built specifically for data science learners with in-browser exercises.
- 🟡 **[Kaggle Learn — Pandas](https://www.kaggle.com/learn/pandas)** — technically Pandas-focused (Module 07), but its early exercises reinforce NumPy-style array thinking well; free and very hands-on.

## 🌐 Websites & Interactive Platforms
- 🟢 **[NumPy Illustrated (Medium/GitHub)](https://github.com/Jash-2000/NumPy-Illustrated)** — a well-known, densely visual cheat-sheet-style guide to array shapes, broadcasting, and axis behavior.
- 🟡 **[LeetCode / HackerRank — NumPy practice problems](https://www.hackerrank.com/domains/python)** — HackerRank specifically has a dedicated NumPy practice track under its Python domain.

## 📚 Books
- 🟢 **"Python for Data Analysis" by Wes McKinney** (creator of Pandas) — its early chapters cover NumPy thoroughly and are considered a standard reference in the field.
- 🟡 **"Elegant SciPy" by Juan Nunez-Iglesias, Stéfan van der Walt, and Harriet Dashnow** — goes deeper into idiomatic, high-performance NumPy usage; a good follow-up once fundamentals are solid.

## 👥 Communities
- **[r/learnpython](https://www.reddit.com/r/learnpython/)** — good for general NumPy troubleshooting, including shape/broadcasting errors.
- **[r/datascience](https://www.reddit.com/r/datascience/)** — broader data science community, useful once you're combining NumPy with real analysis questions.
- **[Stack Overflow — [numpy] tag](https://stackoverflow.com/questions/tagged/numpy)** — nearly every `ValueError` about shapes or broadcasting has already been answered here.

# 📚 Module 10 References: EDA & Statistics

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[StatQuest with Josh Starmer](https://www.youtube.com/@statquest)** — widely considered the best free channel for building genuine statistical intuition (p-values, t-tests, distributions), with a clear, patient teaching style.
- 🟢 **[Krish Naik — EDA in Python](https://www.youtube.com/@krishnaik06)** — practical, dataset-driven walkthroughs of full EDA workflows.
- 🟡 **[Josh Starmer — Confidence Intervals Clearly Explained](https://www.youtube.com/@statquest)** — a focused StatQuest video specifically clarifying the confidence interval misinterpretation covered in this module.

## 📖 Official Documentation
- 🟢 **[SciPy — `scipy.stats` Reference](https://docs.scipy.org/doc/scipy/reference/stats.html)** — the authoritative reference for every hypothesis test and distribution function used in this module.
- 🟢 **[Pandas — Descriptive Statistics](https://pandas.pydata.org/docs/user_guide/basics.html#descriptive-statistics)** — official reference for `.mean()`, `.std()`, `.skew()`, and related methods.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — Python Statistics Fundamentals](https://realpython.com/python-statistics/)** — thorough, practical introduction covering exactly this module's descriptive statistics.
- 🟢 **[Real Python — Hypothesis Testing With Python](https://realpython.com/python-hypothesis-testing/)** — clear, example-driven guide to hypothesis testing and t-tests.
- 🟡 **[Towards Data Science — A Complete Guide to Confidence Intervals](https://towardsdatascience.com/)** — search this title; a commonly recommended deep dive that clears up the interpretation nuance covered in this module.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Data Cleaning](https://www.kaggle.com/learn/data-cleaning)** and **[Intro to Statistics resources on Khan Academy](https://www.khanacademy.org/math/statistics-probability)** — free, foundational statistics courses that pair well with this module's practical Python focus.
- 🟡 **[DataCamp — Statistical Thinking in Python](https://www.datacamp.com/courses/statistical-thinking-in-python-part-1)** — paid, hands-on, in-browser exercises specifically on this module's topics.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Seeing Theory (Brown University)](https://seeing-theory.brown.edu/)** — a beautifully visual, interactive introduction to probability and statistics concepts, including distributions and hypothesis testing.
- 🟡 **[Spurious Correlations](https://www.tylervigen.com/spurious-correlations)** — a fun, memorable collection of hilariously unrelated but strongly-correlated variables — the perfect illustration of "correlation is not causation."

## 📚 Books
- 🟢 **"Practical Statistics for Data Scientists" by Peter Bruce, Andrew Bruce, and Peter Gedeck** — widely considered the standard, most directly job-relevant statistics book for data scientists, covering exactly this module's material and beyond.
- 🟡 **"How to Lie with Statistics" by Darrell Huff** — a classic, short, highly readable book on how statistics gets misused and misinterpreted — great companion reading for building the skepticism this module encourages.

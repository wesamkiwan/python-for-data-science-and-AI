# 📚 Module 11 References: SQL for Data Scientists

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[freeCodeCamp — SQL Full Course for Beginners](https://www.youtube.com/@freecodecamp)** — comprehensive, widely recommended full course covering everything in this module and more.
- 🟢 **[Socratica — SQL Tutorials](https://www.youtube.com/@Socratica)** — short, clear, focused videos on individual SQL concepts (joins, subqueries, aggregates).
- 🟡 **[Alex the Analyst — SQL for Data Analytics](https://www.youtube.com/@AlexTheAnalyst)** — practical, data-analyst-focused SQL series with real business-style examples.

## 📖 Official Documentation
- 🟢 **[SQLite — Official Documentation](https://www.sqlite.org/docs.html)** — the authoritative reference for the exact database engine used in this module.
- 🟢 **[Python Docs — `sqlite3`](https://docs.python.org/3/library/sqlite3.html)** — official reference for using SQLite from Python.
- 🟢 **[Pandas — `read_sql`](https://pandas.pydata.org/docs/reference/api/pandas.read_sql.html)** — official reference for loading query results directly into a DataFrame.

## 📝 Tutorials & Articles
- 🟢 **[Mode Analytics — SQL Tutorial](https://mode.com/sql-tutorial/)** — an excellent, thorough, business-analytics-focused SQL tutorial, widely used and recommended.
- 🟢 **[Real Python — Data Management With Python, SQLite, and SQLAlchemy](https://realpython.com/python-sql-libraries/)** — covers `sqlite3` and beyond, with practical examples.
- 🟡 **[Use The Index, Luke!](https://use-the-index-luke.com/)** — a deeper resource on how SQL queries actually execute and how to write efficient ones; useful once fundamentals are solid.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Intro to SQL](https://www.kaggle.com/learn/intro-to-sql)** and **[Advanced SQL](https://www.kaggle.com/learn/advanced-sql)** — free, short, hands-on courses covering this module's exact scope and beyond (window functions, nested data).
- 🟢 **[SQLZoo](https://sqlzoo.net/)** — free, interactive, browser-based SQL practice with instant feedback.
- 🟡 **[Mode SQL Tutorial (interactive)](https://mode.com/sql-tutorial/introduction-to-sql)** — same as above, but with a runnable in-browser SQL editor.

## 🌐 Websites & Interactive Platforms
- 🟢 **[SQLite Online](https://sqliteonline.com/)** — practice SQL directly in a browser, no installation needed.
- 🟢 **[LeetCode — Database problems](https://leetcode.com/problemset/database/)** — a large set of real interview-style SQL problems, from easy to hard.
- 🟡 **[HackerRank — SQL](https://www.hackerrank.com/domains/sql)** — another strong source of SQL practice problems, commonly used for interview prep.

## 📚 Books
- 🟢 **"Learning SQL" by Alan Beaulieu** — widely recommended as the best true-beginner SQL book, covering exactly this module's fundamentals in depth.
- 🟡 **"SQL Performance Explained" by Markus Winand** — a focused, more advanced book specifically on query performance and indexing, for after the fundamentals are comfortable.

## 👥 Communities
- **[r/SQL](https://www.reddit.com/r/SQL/)** — active, beginner-friendly subreddit for SQL questions across all database engines.
- **[Stack Overflow — [sql] / [sqlite] tags](https://stackoverflow.com/questions/tagged/sql)** — enormous archive of SQL questions; nearly every syntax question or error has already been answered.

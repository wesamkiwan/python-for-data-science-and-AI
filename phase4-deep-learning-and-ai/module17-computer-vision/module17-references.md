# 📚 Module 17 References: Computer Vision (CNNs)

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[3Blue1Brown — Convolutional Neural Networks](https://www.youtube.com/@3blue1brown)** — outstanding visual intuition for convolution, extending the neural network series from Module 16.
- 🟢 **[StatQuest — Convolutional Neural Networks](https://www.youtube.com/@statquest)** — clear, patient walkthrough of CNN mechanics.
- 🟢 **[Daniel Bourke — PyTorch Computer Vision](https://www.youtube.com/@mrdbourke)** — thorough, hands-on continuation of his PyTorch series specifically for CNNs and transfer learning.

## 📖 Official Documentation
- 🟢 **[PyTorch — torchvision models](https://pytorch.org/vision/stable/models.html)** — the authoritative reference for every pretrained model available for transfer learning.
- 🟢 **[PyTorch — Transfer Learning Tutorial](https://pytorch.org/tutorials/beginner/transfer_learning_tutorial.html)** — the official, detailed walkthrough matching this module's Module 17c content.
- 🟢 **[Keras — Transfer Learning & Fine-tuning Guide](https://keras.io/guides/transfer_learning/)** — the official, comprehensive Keras guide on this exact topic.
- 🟢 **[Keras — Image Data Augmentation Layers](https://keras.io/api/layers/preprocessing_layers/image_augmentation/)** — reference for every augmentation layer Keras provides.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — PyTorch vs. Keras for CNNs](https://realpython.com/)** — search this or similar titles for a practical framework comparison specific to computer vision.
- 🟢 **[CS231n (Stanford) — Convolutional Neural Networks for Visual Recognition](https://cs231n.github.io/)** — legendary, freely available course notes; the deeper technical reference for CNN fundamentals.
- 🟡 **[Machine Learning Mastery — A Gentle Introduction to Transfer Learning](https://machinelearningmastery.com/transfer-learning-for-deep-learning/)** — a practical, widely-cited introduction.

## 🎓 Courses & Learning Portals
- 🟢 **[Kaggle Learn — Computer Vision](https://www.kaggle.com/learn/computer-vision)** — free, short, hands-on course covering CNNs and transfer learning using Keras.
- 🟢 **[fast.ai — Practical Deep Learning for Coders](https://course.fast.ai/)** — heavily emphasizes transfer learning as the default, practical approach, using PyTorch.
- 🟡 **[Andrew Ng's Deep Learning Specialization — Convolutional Neural Networks course](https://www.coursera.org/specializations/deep-learning)** — free to audit; strong theoretical grounding.

## 🌐 Websites & Interactive Platforms
- 🟢 **[CNN Explainer](https://poloclub.github.io/cnn-explainer/)** — an outstanding interactive visualization of a real CNN's layers processing an actual image, directly in the browser.
- 🟡 **[Papers With Code — Image Classification](https://paperswithcode.com/task/image-classification)** — see current state-of-the-art models and their architectures, most built on transfer learning.

## 📚 Books
- 🟢 **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron** — its CNN and transfer learning chapters cover exactly this module's material.
- 🟡 **"Deep Learning for Computer Vision" by Rajalingappaa Shanmugamani** — a more specialized book focused entirely on computer vision applications.

# 📚 Module 16 References: Deep Learning Foundations

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[3Blue1Brown — Neural Networks series](https://www.youtube.com/@3blue1brown)** — the single best free visual intuition for neurons, backpropagation, and gradient descent available anywhere; watch this before anything else in this module.
- 🟢 **[StatQuest — Neural Networks](https://www.youtube.com/@statquest)** — clear, patient explanations of the math behind forward passes, loss functions, and backpropagation.
- 🟢 **[Daniel Bourke — PyTorch for Deep Learning](https://www.youtube.com/@mrdbourke)** — a widely recommended, extremely thorough free PyTorch course.
- 🟢 **[freeCodeCamp — TensorFlow 2.0 Course](https://www.youtube.com/@freecodecamp)** — comprehensive, hands-on TensorFlow/Keras course.

## 📖 Official Documentation
- 🟢 **[PyTorch — 60 Minute Blitz](https://pytorch.org/tutorials/beginner/deep_learning_60min_blitz.html)** — the official, concise introduction to tensors, autograd, and building networks.
- 🟢 **[PyTorch — nn.Module documentation](https://pytorch.org/docs/stable/generated/torch.nn.Module.html)** — the authoritative reference for defining custom networks.
- 🟢 **[Keras — Official Guides](https://keras.io/guides/)** — comprehensive official guides covering `Sequential`, `.compile()`/`.fit()`, and callbacks.
- 🟢 **[TensorFlow — Keras Overview](https://www.tensorflow.org/guide/keras)** — official TensorFlow documentation for the Keras API used throughout this module.

## 📝 Tutorials & Articles
- 🟢 **[Real Python — PyTorch vs TensorFlow](https://realpython.com/pytorch-vs-tensorflow/)** — a balanced, practical comparison matching this module's Module 16c discussion.
- 🟢 **[Machine Learning Mastery — Dropout Regularization](https://machinelearningmastery.com/dropout-regularization-deep-learning-models-keras/)** — a focused, practical guide to dropout specifically.
- 🟡 **[colah's blog — Understanding Backpropagation](https://colah.github.io/)** — a well-known, deeper technical explanation of backpropagation for those wanting more mathematical grounding.

## 🎓 Courses & Learning Portals
- 🟢 **[Andrew Ng's Deep Learning Specialization (Coursera)](https://www.coursera.org/specializations/deep-learning)** — the most famous, thorough deep learning course available; free to audit.
- 🟢 **[Kaggle Learn — Intro to Deep Learning](https://www.kaggle.com/learn/intro-to-deep-learning)** — free, short, hands-on introduction using Keras.
- 🟡 **[fast.ai — Practical Deep Learning for Coders](https://course.fast.ai/)** — free, highly practical, code-first course, using PyTorch underneath.

## 🌐 Websites & Interactive Platforms
- 🟢 **[TensorFlow Playground](https://playground.tensorflow.org/)** — an outstanding interactive tool for building intuition about layers, activation functions, and overfitting, directly in the browser.
- 🟡 **[Distill.pub](https://distill.pub/)** — beautifully visual, in-depth articles on deep learning concepts (archived but still excellent).

## 📚 Books
- 🟢 **"Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow" by Aurélien Géron** — its deep learning chapters cover exactly this module's material, with both frameworks represented.
- 🟡 **"Deep Learning" by Ian Goodfellow, Yoshua Bengio, and Aaron Courville** (free online) — the definitive, comprehensive theoretical textbook, for those wanting to go much deeper into the mathematics.

## 👥 Communities
- **[r/MachineLearning](https://www.reddit.com/r/MachineLearning/)** and **[r/deeplearning](https://www.reddit.com/r/deeplearning/)** — active communities for deep learning discussions.
- **[PyTorch Forums](https://discuss.pytorch.org/)** and **[Stack Overflow — [pytorch] / [tensorflow] / [keras] tags](https://stackoverflow.com/questions/tagged/pytorch)** — nearly every framework-specific error has already been answered here.

# 📚 Module 18 References: NLP & Transformers

⚠️ Links may change over time — if one is broken, search the resource's name directly.

## 📺 YouTube Videos & Channels
- 🟢 **[3Blue1Brown — Attention in Transformers](https://www.youtube.com/@3blue1brown)** — outstanding visual intuition for self-attention, extending the neural network series from Module 16.
- 🟢 **[StatQuest — Transformers and Attention](https://www.youtube.com/@statquest)** — clear, patient breakdown of the attention mechanism's math.
- 🟢 **[Hugging Face — Official Course Videos](https://www.youtube.com/@HuggingFace)** — short, focused videos directly from the team behind the `transformers` library.
- 🟡 **[Andrej Karpathy — Let's build GPT from scratch](https://www.youtube.com/@AndrejKarpathy)** — a legendary, code-first deep dive building a Transformer from the ground up — excellent for solidifying this module's concepts (best attempted after this module, not before).

## 📖 Official Documentation
- 🟢 **[Hugging Face — NLP Course](https://huggingface.co/learn/nlp-course)** — the official, free, extremely thorough course covering tokenization, Transformers, and `pipeline()` in depth; strongly recommended as a direct follow-up to this module.
- 🟢 **[Hugging Face — Transformers Documentation](https://huggingface.co/docs/transformers/index)** — the authoritative reference for the library used throughout this module.
- 🟢 **[Hugging Face — Pipelines Documentation](https://huggingface.co/docs/transformers/main_classes/pipelines)** — the definitive reference for every supported pipeline task and its parameters (check here when API names change between versions).

## 📝 Tutorials & Articles
- 🟢 **[Jay Alammar — The Illustrated Transformer](https://jalammar.github.io/illustrated-transformer/)** — one of the most beloved, widely-cited visual explanations of the Transformer architecture ever written.
- 🟢 **[Jay Alammar — The Illustrated BERT, ELMo, and co.](https://jalammar.github.io/illustrated-bert/)** — an excellent companion piece covering embeddings and encoder-style models specifically.
- 🟢 **["Attention Is All You Need" (the original Transformer paper)](https://arxiv.org/abs/1706.03762)** — the foundational 2017 paper; worth reading once the concepts feel solid, to see the original source.

## 🎓 Courses & Learning Portals
- 🟢 **[Hugging Face NLP Course](https://huggingface.co/learn/nlp-course)** — (also listed above) free, hands-on, directly matches this module's scope and goes considerably further.
- 🟢 **[Kaggle Learn — Natural Language Processing](https://www.kaggle.com/learn/natural-language-processing)** — free, short, practical introduction.
- 🟡 **[Stanford CS224n — NLP with Deep Learning](http://web.stanford.edu/class/cs224n/)** — freely available lecture materials for the deeper theoretical foundation.

## 🌐 Websites & Interactive Platforms
- 🟢 **[Hugging Face Hub](https://huggingface.co/models)** — browse thousands of pretrained models for every NLP task imaginable, with model cards describing their training and intended use.
- 🟢 **[BertViz](https://github.com/jessevig/bertviz)** — an interactive tool for visualizing attention patterns inside real Transformer models.
- 🟡 **[Hugging Face Spaces](https://huggingface.co/spaces)** — try out hundreds of live NLP model demos directly in the browser.

## 📚 Books
- 🟢 **"Natural Language Processing with Transformers" by Lewis Tunstall, Leandro von Werra, and Thomas Wolf** — written by Hugging Face team members; the definitive practical book on exactly this module's material.
- 🟡 **"Speech and Language Processing" by Jurafsky and Martin** (free draft chapters online) — the classic, comprehensive NLP textbook, covering both classical and modern deep learning approaches.
